# SourceMetric brand assets

The active identity is an original SourceMetric S monogram made from a connected three-node source signal, paired with a SourceMetric wordmark. It was generated using the built-in imagegen tool. Only the emerald/charcoal palette takes inspiration from Supabase; the symbol and typography are independent and do not use Supabase assets.

`sourcemetric-logo-v2.png` preserves the final generated image unchanged. `logo-v2-prompt.txt` contains the final generation prompt. The v2 SVGs embed this PNG and frame the wordmark or symbol with viewBox; these are raster-backed SVG wrappers, not vector redraws. The source has a charcoal background, and app branding uses lighten blending to integrate it with dark surfaces.

The app uses `sourcemetric-wordmark-v2.svg` for navigation and `sourcemetric-mark-v2.svg` for the footer and browser favicon. The original v1 PNGs, SVGs, and prompt remain in this directory as archived source assets.

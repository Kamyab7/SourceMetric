# SourceMetric brand assets

The selected logo is the first image generated in this chat using the built-in image tool. sourcemetric-logo.png preserves that original. The wordmark and favicon SVGs embed the original PNG and frame it with viewBox; they are raster-backed SVG wrappers, not vector redraws. Transparency is preserved.

The app uses sourcemetric-wordmark.svg in navigation and sourcemetric-mark.svg in its footer and browser favicon.
